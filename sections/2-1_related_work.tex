\section{Many parameter settings fit the same data, and the procedure picks one}
\label{sec:bg_solutionset}
% ─────────────────────────────────────────────────────────────────────────────
% Job of this section: establish the solution set, and that the training
% procedure rather than the task selects a member of it. This is the premise
% the whole thesis rests on, so it comes first.

\subsection{An overparameterised network has many settings that fit}
\label{sec:bg_interpolation}

\paragraph{Fitting is not the constraint.}
% A network with more parameters than training examples can fit the data
% exactly, including random labels, so reaching zero training loss says little
% about which function was found. Keys: zhang_rethinking_2017.

\paragraph{The solutions form a set rather than a point.}
% Many settings reach the same training loss, and they differ in properties the
% loss does not see. Say plainly that this thesis is about one such property.
% Keys: neyshabur_search_2015, belkin_reconciling_2019.

\subsection{The training procedure selects among them}
\label{sec:bg_implicitbias}
% The term to introduce here, in plain words, is implicit bias: a preference
% among the settings that fit, produced by the procedure rather than by the
% objective.

\paragraph{Gradient descent has a bias that can be stated exactly.}
% On separable data, gradient descent on the logistic loss converges in
% direction to the maximum margin solution, so the procedure fixes a property
% the objective leaves open. Keys: soudry_implicit_2018.

\paragraph{The geometry of the update decides which property is minimised.}
% Steepest and mirror descent under different norms select different minima of
% the same objective. Keys: gunasekar_characterizing_2018.

\paragraph{The scale of the initialisation moves the network between two regimes.}
% Small initialisation gives a rich, feature learning regime and large
% initialisation a kernel regime, and the two reach different solutions. Note
% that this axis has been connected to grokking. Keys: woodworth_kernel_2020,
% kumar_grokking_2024.

\paragraph{Changing the optimizer changes the solution, not only the speed.}
% Adaptive methods reach solutions that generalise differently from those of
% plain gradient descent at matched training loss. Keys: wilson_marginal_2017.

\subsection{Some of the choice is visible in what the update conserves}
\label{sec:bg_conserved}
% This subsection is the machinery the grokking chapter's propositions use, so
% it has to be here rather than in that chapter.

\paragraph{Gradient flow on a homogeneous network keeps layers balanced.}
% The difference of squared norms across a layer boundary is constant under
% gradient flow, so the initialisation's imbalance survives training. Keys:
% du_algorithmic_2018.

\paragraph{Each symmetry of the parameterisation gives a conserved quantity.}
% Rescale and permutation symmetries imply quantities the dynamics cannot
% change, and weight decay and momentum break them in known ways. Keys:
% kunin_neural_2021.

\paragraph{A conserved ratio is what freezes a profile.}
% State the consequence the thesis uses without claiming it as a result here.
% If the flow conserves the ratios between units, no amount of training can
% reshape the relative sizes it started with, and a rule that conserves
% differences instead can. Point forward to Chapter~\ref{chap:grokking}.

\subsection{This literature has asked about norms, not about how many units carry the computation}
\label{sec:bg_biasgap}

\paragraph{The properties it characterises are global.}
% Norm, margin, rank and effective dimension are properties of the whole
% parameter vector. The closest to a structural claim is the low rank bias of
% deep matrix factorisation. Keys: arora_implicit_2019, gunasekar_characterizing_2018.

\paragraph{And the part of the procedure it varies is the optimizer.}
% The results above vary the optimizer or the initialisation scale. The
% computation that assigns each parameter its share of the error is held at
% backpropagation throughout. Name that as the opening this thesis uses.

\section{How a computation is spread over neurons is an old question with measures}
\label{sec:bg_coding}
% ─────────────────────────────────────────────────────────────────────────────
% Job of this section: import the neuroscience framing, and above all the
% measures and the consequences. The reader must leave this section
% believing that the spread is a real property with real costs, and knowing how
% it is quantified.

\subsection{Sparse and distributed codes are the two ends}
\label{sec:bg_sparsedistributed}

\paragraph{The question and the two answers.}
% Whether a stimulus is represented by a few highly selective neurons or by a
% pattern over many is the oldest form of this question. Give both names.
% Keys: barlow_single_1972, hinton_distributed_1986.

\paragraph{Sparsity as a principle derived from the input statistics.}
% Optimising for a sparse code of natural images produces oriented receptive
% fields resembling those of primary visual cortex, which is sparsity derived
% rather than assumed. Keys: olshausen_emergence_1996, olshausen_sparse_2004,
% foldiak_sparse_1995.

\paragraph{Highly selective cells do exist.}
% Single neurons in the human medial temporal lobe respond to one concept
% across very different images. State it as evidence for the sparse end, not as
% a settlement of the debate. Keys: quiroga_invariant_2005.

\subsection{Each end buys something and gives something up}
\label{sec:bg_codingprice}
% This subsection is the one the thesis leans on hardest, because the trade off
% it describes is the one Chapter~\ref{chap:grokking} measures.

\paragraph{A distributed code degrades gracefully.}
% If many neurons carry a signal, losing some of them changes the summed signal
% little, and the fluctuation shrinks with the number carrying it. This is the
% population coding argument, and it is the biological form of the bound the
% grokking chapter proves. Keys: averbeck_neural_2006, rolls_relative_1990.

\paragraph{A sparse code interferes less and stores more.}
% Fewer shared neurons means a new association disturbs less of what is already
% there, and capacity arguments favour sparse connectivity. Keys:
% rolls_relative_1990, litwinkumar_optimal_2017.

\paragraph{Artificial networks show the same two effects.}
% Deleting units or weights from a trained network degrades it unevenly,
% ablating single directions predicts generalisation, sparse subnetworks train
% to full accuracy, and dropout buys redundancy by construction. Keys:
% lecun_optimal_1989, han_learning_2015, morcos_importance_2018,
% zhou_revisiting_2018, frankle_lottery_2019, srivastava_dropout_2014,
% ahmad_dense_2019.

\subsection{The spread can be measured, and the measure has to be chosen}
\label{sec:bg_measures}

\paragraph{Participation ratio counts how many parts effectively contribute.}
% Define it in words, say it is basis independent, and say that multiplying by
% the number of units reads as an effective count. This is the measure the
% thesis uses. Keys: litwinkumar_optimal_2017, gao_simplicity_2015.

\paragraph{How many features a unit carries is a different axis.}
% Polysemantic units and superposition ask how many features share a neuron.
% That is not the same question as how many neurons share a computation, and
% the two must not be conflated. Keys: elhage_toy_2022,
% bricken_monosemanticity_2023.

\paragraph{A basis dependent measure can mislead.}
% Spectral entropy and similar quantities depend on the basis they are computed
% in. Say that the thesis therefore leads with a basis independent measure and
% point to Chapter~\ref{chap:grokking} for the case where the two disagree.

\section{Grokking is where the layout can be read off}
\label{sec:bg_grokking}
% ─────────────────────────────────────────────────────────────────────────────
% Job of this section: explain the phenomenon, explain that its circuit is
% known at the level of single neurons, and end on the assumption the thesis
% tests. Gloss "grokking" inline at first use.

\subsection{Generalisation can arrive long after the training data is fitted}
\label{sec:bg_grokphenomenon}

\paragraph{The phenomenon.}
% Training accuracy reaches one, test accuracy sits at chance for thousands of
% epochs, then climbs abruptly. Give the setting: small algorithmic tasks,
% weight decay, full batch. Keys: power_grokking_2022.

\paragraph{The explanations offered.}
% Weight norm and the distance from initialisation, circuit efficiency, the
% rich and lazy regimes, an effective theory of representation learning, and
% hidden progress that standard metrics miss. Keys: liu_omnigrok_2022,
% varma_explaining_2023, kumar_grokking_2024, liu_towards_2022,
% barak_hidden_2022.

\paragraph{And that an optimizer can decide whether it happens at all.}
% Adaptive optimizers change whether and when grokking occurs, which is the
% closest the literature comes to the thesis's question and still does not ask
% which solution is reached. Keys: thilak_slingshot_2022.

\subsection{For modular arithmetic the circuit is known neuron by neuron}
\label{sec:bg_grokcircuit}

\paragraph{The Fourier computation.}
% The embedding maps operands onto a few frequencies, the hidden layer combines
% them into sine and cosine of the sum, and the logit for a candidate peaks at
% the correct answer. Keys: nanda_progress_2023, gromov_grokking_2023.

\paragraph{The same analysis for a group that is not commutative.}
% Composition in a permutation group is solved with the group's irreducible
% representations rather than frequencies. Keys: chughtai_toy_2023.

\paragraph{The characterisation bundles two properties.}
% Max margin analysis of a one hidden layer model gives neurons that each tune
% to a single frequency and a computation carried by many units at once. Say
% clearly that these are two separate properties, because the thesis separates
% them. Keys: morwani_feature_2024.

\paragraph{The circuit is not unique even under backpropagation.}
% A different algorithm appears under other hyperparameters, a sparse
% generalising subnetwork can be separated from a dense memorising one, and a
% small initialisation condenses a network onto few effective neurons. Keys:
% zhong_clock_2023, merrill_tale_2023, luo_phase_2021.

\subsection{The assumption is that the task fixes the circuit}
\label{sec:bg_universality}

\paragraph{Universality, stated.}
% The claim that every network solving a task finds the same circuit, so a
% circuit found in one network stands for the task. Keys: chughtai_toy_2023,
% olah_zoom_2020.

\paragraph{Two levels that the evidence does not separate.}
% What is computed, and how many units carry it. The first is not contested by
% this thesis. Say that every network behind the evidence above was trained
% with backpropagation, and stop there. No claim about what we found.

\section{The training procedure has parts, and each of them can be varied}
\label{sec:bg_rules}
% ─────────────────────────────────────────────────────────────────────────────
% Job of this section: give the reader the rules Chapter~\ref{chap:grokking}
% compares, organised so that the organising property is visible. The
% vocabulary (credit assignment algorithm, optimizer, learning rule) is defined
% in Chapter~\ref{chap:introduction} and used plainly here.

\subsection{Credit can be assigned without backpropagation}
\label{sec:bg_credit}

\paragraph{Why alternatives were looked for.}
% Backpropagation needs the transpose of the forward weights, which has no
% obvious biological implementation. Keys: rumelhart_learning_1986,
% crick_recent_1989.

\paragraph{Random feedback is enough to learn.}
% Feedback alignment routes the error through a fixed random matrix and the
% forward weights align to it, and the direct form skips the layer chain
% entirely. Note the finding that alignment happens early and memorisation
% follows. Keys: lillicrap_random_2016, nokland_direct_2016,
% refinetti_align_2021.

\paragraph{Curvature and sign.}
% Natural gradient and its Kronecker factored approximation precondition by
% curvature, and sign methods discard the magnitude entirely, with convergence
% results that separate the plain sign update from an interpolated one. Keys:
% amari_natural_1998, martens_optimizing_2015, bernstein_signsgd_2018,
% karimireddy_error_2019, chen_lion_2024.

\paragraph{Energy based and control based rules.}
% Predictive coding, equilibrium propagation, target propagation, the
% forward-forward algorithm, and deep feedback control, which replaces the
% backward pass with a controller that drives the network towards the target.
% Keys: whittington_approximation_2017, scellier_equilibrium_2017,
% lee_difference_2015, hinton_forward_2022, meulemans_credit_2021,
% meulemans_least_2022.

\paragraph{What all of them are asked.}
% Every one of these is evaluated on whether it matches backpropagation's
% accuracy. Which solution it selects is left open, and none has been run on a
% task whose circuit is known. Keys: mallinar_emergence_2025 for the closest case, a
% kernel method that groks without backpropagation and so has no per unit
% circuit to read.

\subsection{Optimizers differ in how many parameters share one normaliser}
\label{sec:bg_grain}
% Present this as one spectrum in one property, because that property is what
% Chapter~\ref{chap:grokking} predicts from.

\paragraph{Per parameter.}
% Running estimates of the gradient's second moment give each weight its own
% step size, and a sign update or a factored estimate does the same thing more
% cheaply. Keys: kingma_adam_2015, tieleman_lecture_2012,
% shazeer_adafactor_2018, chen_lion_2024.

\paragraph{Per layer and per matrix.}
% Trust ratios rescale a whole layer by one scalar, and preconditioners
% transform a whole weight matrix. Keys: you_batch_2017, you_batch_2020,
% gupta_shampoo_2018, jordan_muon_2024.

\paragraph{Per neuron.}
% A normaliser shared by exactly the weights entering one neuron, and the
% reparameterisation that constrains those weights instead of the update.
% Keys: liu_learning_2021, salimans_weight_2016.

\paragraph{The property that orders them.}
% State the spectrum without claiming the result: these methods differ in which
% group of parameters shares one normaliser, from a single weight to a whole
% matrix. Point forward to Chapter~\ref{chap:grokking}.

\subsection{What is known about these rules is convergence and accuracy}
\label{sec:bg_rulesgap}

\paragraph{Per method results exist, a comparison at a matched setting does not.}
% Each rule has its own convergence analysis and its own benchmark table. No
% study holds task, data, architecture and optimizer fixed, varies the rule, and
% reads the resulting solution at the level of single neurons.

\section{The same question can be asked of a weight matrix, where the objective is the knob}
\label{sec:bg_attention}
% ─────────────────────────────────────────────────────────────────────────────
% Job of this section: get the reader to the object Chapter~\ref{chap:attention}
% studies, which is the product of the query and key matrices, and to the fact
% that the two objectives differ in which token pairs enter the update.

\subsection{Query and key act only through their product}
\label{sec:bg_qk}

\paragraph{Attention as a score over token pairs.}
% Define attention in words, name query, key and value, and say the scores are
% a linear map of the embeddings up to the row-wise softmax. Keys:
% etal_attention_2017.

\paragraph{The product is the object worth studying.}
% The two matrices only ever appear as one product, which acts as a bilinear
% form on the embeddings, so structure in either one separately can be
% reparameterised away. Keys: elhage_mathematical_2021, dar_analyzing_2023.

\subsection{The two pretraining objectives differ in which pairs enter the update}
\label{sec:bg_objectives}

\paragraph{Bidirectional prediction.}
% A masked token is predicted from the whole sequence, so a pair contributes in
% both orders. Keys: devlin_bert_2019, warner_smarter_2024.

\paragraph{Autoregressive prediction.}
% Each token is predicted from its predecessors only, so a token is context for
% every later token and a target once. Keys: brown_language_2020,
% touvron_llama_2023a, radford_improving_2018.

\paragraph{Why that difference is the interesting one.}
% State it neutrally: the two objectives define different sets of pairs, and the
% update to the attention weights is a sum over those pairs. Point forward to
% Chapter~\ref{chap:attention}.

\subsection{Reading structure off attention weights has been attempted from the outside}
\label{sec:bg_interp}

\paragraph{Probing asks what a representation contains.}
% A light classifier on frozen features tests whether information is decodable,
% and the control task literature shows how easily that overstates what the
% model uses. Keys: belinkov_probing_2022, hewitt_designing_2019.

\paragraph{Attention maps are an unreliable guide.}
% The attention distribution can be changed substantially without changing the
% output, and the reply to that result is worth citing too. Keys:
% jain_attention_2019, wiegreffe_attention_2019.

\paragraph{Features and circuits.}
% Sparse autoencoders recover interpretable features, and circuit analysis
% identifies subgraphs that implement a behaviour, such as induction heads.
% Keys: huben_sparse_2024, bricken_monosemanticity_2023, olah_zoom_2020,
% olsson_context_2022, geva_transformer_2021.

\paragraph{All of it works from activations rather than from the update.}
% These methods examine a trained network. None of them derives what structure
% the training objective must produce, which is the opening the attention
% chapter uses.

\section{Structure can be supplied instead of learned, which makes measurement the hard part}
\label{sec:bg_supplied}
% ─────────────────────────────────────────────────────────────────────────────
% Job of this section: cover the three side chapters of Part IV at background

\subsection{A learner needs a bias, and it can be placed at several points}
\label{sec:bg_inductive}

\paragraph{Why a bias is necessary at all.}
% No procedure generalises without one, and the trade against variance is the
% classical statement. Keys: wolpert_free_1997, etal_neural_1992,
% mitchell_need_1980.

\paragraph{In the architecture.}
% Weight sharing gives translation equivariance, and the general treatment
% derives architectures from the symmetries of the domain. Keys:
% etal_gradient_1998, bronstein_geometric_2021.

\paragraph{In the input representation.}
% Known physics can be added to the loss or the input rather than left to be
% discovered. Point forward to Chapter~\ref{chap:hounsfield}. Keys:
% raissi_physics_2019.

\paragraph{At inference time.}
% Retrieval grounds a prediction in an external index, with lexical matching,
% dense retrieval and a cross encoder as the standard components. Point forward
% to Chapter~\ref{chap:retrieval}. Keys: lewis_retrieval_2021,
% borgeaud_improving_2022, robertson_probabilistic_2009, karpukhin_dense_2020,
% nogueira_passage_2019.

\subsection{A latent world model predicts forward, and its errors compound}
\label{sec:bg_worldmodels}

\paragraph{Predicting in a learned latent space.}
% The state is encoded, the transition is applied in that space, and no pixels
% are reconstructed. Keys: lecun_path_2022, assran_self_2023,
% hafner_mastering_2023, schwarzer_data_2021.

\paragraph{Why a rollout drifts.}
% Composing a nonlinear map amplifies each step's error by its Lipschitz
% constant, so error can grow without bound over a horizon.

\paragraph{Constraining the operator's spectrum is the standard remedy.}
% A linear transition whose spectral radius is bounded turns a product of
% Lipschitz constants into a bound that stays flat in the horizon. Keys:
% lusch_deep_2018, azencot_forecasting_2020, mamakoukas_memory_2020.

\subsection{Scoring a rollout needs a readout, and the readout can decide the answer}
\label{sec:bg_scoring}

\paragraph{A probe from latent to physical state is the usual readout.}
% It is fitted on the training latents and applied to rollout latents. Keys:
% belinkov_probing_2022, hewitt_designing_2019.

\paragraph{A prediction loss in latent space fixes no scale.}
% A loss invariant to the scale of the representation leaves that scale free,
% and the related collapse phenomena in self-supervised learning show what a
% free direction can do. Keys: grill_bootstrap_2020, chen_exploring_2021,
% jing_understanding_2022.

\paragraph{A predictor that learns nothing is the control that catches this.}
% Several fields have found headline results that a trivial baseline matches,
% and the response was a protocol rather than a new model. This is the standard
% the thesis holds its own comparisons to. Keys: dacrema_really_2019,
% musgrave_metric_2020, lin_neural_2019, henderson_deep_2018.

\subsection{An assembly is a set of neurons that support each other}
\label{sec:bg_assemblies}

\paragraph{Stochastic recurrent networks and what they need.}
% A constraint satisfaction network tuned by plasticity, and the restriction

\subsection{Dynamic links, nets and the binding problem}
\label{sec:bg_binding}

\paragraph{Correlation theory and connections that are selected, not fixed.}
% Representation by temporarily selected connections rather than by activity

% malsburg_correlation_1981, malsburg_concerning_2018.

\paragraph{The binding problem.}
% Why unstructured activation over feature units cannot say which features
% belong to the same object, and the perceptual grouping this connects to.

\paragraph{Structured alternatives inside deep learning.}
% Capsules replace a scalar activation with a vector carrying pose and route

\section{The gap}
\label{sec:bg_gap}
% ─────────────────────────────────────────────────────────────────────────────
% Job of this section: name the gap and stop. Half a page. No results, no
% roadmap paragraph, no repetition of the contributions list from
% Chapter~\ref{chap:introduction}. One clause per part at most.

\paragraph{The question has not been asked with the procedure varied.}
% Section~\ref{sec:bg_solutionset} gives a literature that varies the optimizer
% and characterises norms. Section~\ref{sec:bg_coding} gives a question about
% how many units carry a computation, with measures and a known price.
% Section~\ref{sec:bg_grokking} gives the one setting where the answer is
% readable. Nobody has put the three together.

\paragraph{Three specific things are missing.}
% A comparison that holds task, data, architecture and optimizer fixed and
% varies the rule. A prediction of the resulting layout from the form of the
% update alone. A measurement of what the layout costs.

\paragraph{And two smaller ones.}
% The same question has not been asked of a Transformer's attention weights
% with the objective as the variable, and the assembly tradition has not been
% read as a layout that is fixed by construction rather than learned.
